# РОЙ

Настольная игра для двоих на шестиугольном поле. Переведите свой рой в улей соперника раньше него. Пчёлы, трутни и королевы, три дизайна, три музыкальные темы, игра против компьютера или вдвоём на одном устройстве.

**Играть:** https://ИМЯ.github.io/roy/ (замените на свой адрес после включения GitHub Pages)

Игру можно установить на телефон или компьютер: «Добавить на главный экран» (iPhone: Safari → «Поделиться») или «Установить приложение» (Chrome). После первого запуска игра работает без интернета.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | вся игра: разметка, стили, код, графика и звук |
| `sw.js` | service worker: работа без сети и обновление версий |
| `manifest.webmanifest` | описание приложения для установки |
| `icons/` | иконки приложения |
| `roy_brief.md` | паспорт проекта: правила, устройство кода, решения |

## Как выпустить обновление

1. Внести правки в `index.html`.
2. Поднять версию **в двух местах одинаково**: `VERSION='…'` в `index.html` и `VERSION='…'` в `sw.js`.
3. Если добавились новые файлы (картинки, звуки), дописать их в список `FILES` в `sw.js`.
4. Сделать коммит в ветку `main`. Через 1–2 минуты GitHub Pages опубликует сайт.
5. У игроков появится плашка «Доступна новая версия игры → Обновить». Текущая партия сохраняется и восстанавливается после обновления.
6. Поставить метку версии: Releases → Draft a new release → тег `v1.3`.

Если версию в `sw.js` не поднять, установленные копии игры обновление не увидят.

Крупные изменения лучше делать в отдельной ветке и сливать в `main`, когда всё проверено.

## Совместимость сохранений

Партия, статистика и настройки хранятся в `localStorage` под ключами `ulei-*`. Не переименовывайте эти ключи. Если меняется формат сохранения партии (`ulei-save`, поле `v`), добавьте перевод старого формата в новый.

## Проверка локально

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Service worker работает только через http(s), а не при открытии файла двойным щелчком.
